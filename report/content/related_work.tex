\section{Related Work}
\label{sec:related}

\paragraph{Collusion and monitoring.} Collusion is one of the main failure modes of interacting AI agents \parencite{hammond2025multiagent}. LLM agents can hide messages in innocuous text \parencite{motwani2024secret}, and steganographic channels can emerge under optimisation and survive output monitors \parencite{mathew2024hidden}. Control protocols and chain-of-thought monitors read agent outputs with another model \parencite{greenblatt2024control, baker2025monitoring}, which is costly across thousands of runs and assumes legible content. We watch the receiver's output distribution instead, which needs neither the message nor the channel.

\paragraph{Foreign content in context.} Indirect prompt injection delivers adversarial text through data \parencite{greshake2023indirect}. \textcite{abdelnabi2025drift} detect the resulting task drift from internal activations, which requires white-box access; we use only the top-$k$ log-probabilities that APIs return.

\paragraph{Entropy as a signal.} Output entropy is a standard baseline for out-of-distribution detection \parencite{hendrycks2017baseline} and uncertainty estimation \parencite{malinin2021uncertainty, kuhn2023semantic, shannon_hallucination}, and a classic network anomaly statistic \parencite{shannon_ddos}. In multi-agent systems it has described orchestration dynamics \parencite{zhu2026orchestrator} and predicted when collaboration helps \parencite{zhao2026doesmultiagentcollaborationhelp}. To our knowledge, no prior work tests whether black-box entropy reveals that an agent's context was disrupted, with a placebo that separates foreign text from useful information and a checker that verifies communication happened.
