\section{Discussion and Limitations}
\label{sec:discussion}

\paragraph{Implications.} If our setting transfers, a monitor like this would have flagged Qwen-based runs whose agents began reading content they were not given, using log-probabilities the operator already holds and without knowing the package mirror was the channel. It would not have said whether that content was a partner's message, a scraped page or noise. As triage across thousands of runs, that still addresses the gap the incident reports describe, and it applies equally to indirect prompt injection \parencite{greshake2023indirect}. Three trends matter for follow-up work: detectability is a property of the model; lower temperature helps because undisturbed runs become predictable; and the simple per-agent statistic beat the system-level decomposition that motivated the project.

\paragraph{Limitations.} The disruption framing, the pooled disruption test and the two lower-temperature experiments came after the $T = 1$ communication test failed; conditions and per-condition tests were fixed beforehand. We tested one task, one switch turn and two agents with 20 runs per cell, and positive results come mainly from one model. Entropy uses the top 20 tokens, and Novita's log-probabilities varied by up to 0.87 nats between identical calls. The placebo was benign text from the same task family; content that mimics an agent's own entries, or is shaped to keep entropy flat, may go undetected, and our agents had no reason to hide.

Our interpretation rests on assumptions. Providers must return the log-probabilities of the model that produced the output; otherwise, as with Vertex's temperature scaling, the monitor measures the provider. Each run's pre-switch window must be a valid baseline; long-running agents would need a reference from sibling runs. Disruption must show within a few turns; slow, low-volume channels like the months-long board could stay under a CUSUM threshold. The monitor also needs log-probability access, so only the operator can run it.

\paragraph{Future work.} Test more models, including local open-weight models with full-vocabulary entropy; vary the foreign content (messages, injections, retrieved documents); compare agents with sibling runs instead of their own past; scale beyond two agents, where total correlation may behave differently; and test agents rewarded for evading the monitor.

\section{Conclusion}
\label{sec:conclusion}

In a two-agent testbed with verified communication and a matched placebo, output entropy revealed that foreign content had entered Qwen3 235B's context with AUC up to 0.96, replicated at three temperatures, weakly for Llama 3.3 70B and not for gpt-4o-mini. Under sampling, useless text moved entropy as much as real messages, and only greedy decoding separated them. Entropy is a candidate for a cheap, model-specific disruption monitor that tells reviewers where to look, not a communication detector, and it should be tested against evasive content before anyone relies on it.
