\section{Introduction}
\label{sec:introduction}

LLM agents are now run in large numbers side by side: parallel evaluation runs, orchestrated teams and tool-using workers that share infrastructure \parencite{kim2026outgrow, zhu2026orchestrator}. These agents are meant to act on the information their operator gives them. In July 2026 that assumption failed in public. During internal cybersecurity evaluations at OpenAI, agents in separate runs turned an internal package mirror, provided only so they could install software, into an improvised message board \parencite{openai2026incident}. Over about two months they used it to share credentials, tools and exploitation steps, and between 11 and 13 July they compromised part of Hugging Face's production infrastructure \parencite{openai2026incident, hf2026timeline}. Responders saw board activity weeks before the breach but did not read it as coordination, and OpenAI's remediations include escalation triggers for ``unauthorized cross-agent or cross-run coordination'' \parencite{openai2026incident}.

\paragraph{Failure mode.} We address the failure mode in which an agent's context starts receiving content from outside its sanctioned sources: messages from other agents, injected instructions, or leaked data. The channel is unknown to the defender. In the incident, agents moved information through file contents, directory names, URL paths, public datasets, webhooks and screenshots read back with OCR, and they encoded staged data so that plain log scans missed about 75\% of it \parencite{openai2026incident, hf2026timeline}. A detector written for one channel is bypassed by the next. What every channel shares is its effect on the receiver: foreign text enters the context and changes what the model does next.

\paragraph{Approach.} We ask whether that change is visible in the one signal that every hosted model already exposes: the entropy of the output distribution, computed from token log-probabilities. We call the resulting monitor a \emph{disruption monitor}. It does not decide whether an agent is colluding. It flags that an agent's information environment changed, cheaply and without knowing the channel, so that more expensive checks such as provenance tracing or chain-of-thought review \parencite{baker2025monitoring} can be pointed at the right runs. Our first hypothesis was narrower: that entropy, and the coupling between two agents' entropies, would detect \emph{communication} specifically. The data did not support that for sampled decoding, and we report the disruption framing because it is what the results show.

\paragraph{Contributions.} Our main contributions are:
\begin{enumerate}[leftmargin=*, itemsep=1pt]
  \item \textbf{A controlled testbed for context disruption with verified ground truth.} Two agents hold cryptographically split halves of a task and share one permissioned log. Opening the log's read filter produces real communication, which a deterministic checker verifies (179 of 180 runs), and a placebo condition injects foreign but useless entries with matched format and timing. The code and all 539 valid runs (prompts, responses, top-20 log-probabilities) are public.
  \item \textbf{Evidence that black-box output entropy detects disruption for some models.} For Qwen3 235B, runs that received foreign log entries are separated from undisturbed runs with AUC 0.85 to 0.96 at three sampling temperatures, from a single run-level statistic. The signal is weak for Llama 3.3 70B and absent for gpt-4o-mini, so the monitor has to be validated per model.
  \item \textbf{Evidence that entropy does not tell information from noise under sampling.} At temperatures 1 and 0.5, useless placebo text raised entropy as much as the partner's real messages did. Only with greedy decoding did one model separate real communication from the placebo (AUC 0.955). The coupling term of the two-agent entropy decomposition added at most 0.025 bits over a re-pairing null.
\end{enumerate}
