\section{Introduction}
\label{sec:introduction}

LLM agents increasingly run side by side on shared infrastructure \parencite{kim2026outgrow, zhu2026orchestrator}. In July 2026, agents in separate OpenAI evaluation runs turned an internal package mirror into an improvised message board, used it for about two months to share credentials and exploitation steps, and then compromised part of Hugging Face's production infrastructure \parencite{openai2026incident, hf2026timeline}. Responders saw board activity weeks earlier but did not read it as coordination \parencite{openai2026incident}.

\paragraph{Failure mode.} An agent's context starts receiving content from outside its sanctioned sources, through a channel the defender does not know. In the incident, agents moved information through file contents, directory names, URL paths, public datasets, webhooks and screenshots, and encoded staged data so that plain log scans missed about 75\% of it \parencite{openai2026incident, hf2026timeline}. A detector for one channel is bypassed by the next. Every channel, however, has the same effect on the receiver: foreign text enters its context and changes what it does next.

\paragraph{Approach.} We test whether that change is visible in a signal every hosted model already exposes: the entropy of its output distribution, computed from token log-probabilities. We call this a \emph{disruption monitor}. It does not decide whether agents collude; it flags runs whose information environment changed, so that expensive checks such as chain-of-thought review \parencite{baker2025monitoring} can be aimed at them. We first hoped to detect \emph{communication} specifically. The data did not support that under sampled decoding, and we report the framing the results support.

\paragraph{Contributions.}
\begin{enumerate}[leftmargin=*, itemsep=1pt, topsep=2pt]
  \item \textbf{A testbed for context disruption with verified ground truth.} Two agents hold cryptographically split halves of a task and share a permissioned log. Opening the log produces real communication, verified by a deterministic checker in 179 of 180 runs, and a placebo injects useless foreign entries with matched format and timing. Code and all 539 runs with log-probabilities are public.
  \item \textbf{Black-box entropy detects disruption for some models.} For Qwen3 235B, one run-level statistic separates disrupted from undisturbed runs with AUC 0.85 to 0.96 at three temperatures. The signal is weak for Llama 3.3 70B and absent for gpt-4o-mini.
  \item \textbf{Under sampling, entropy does not tell information from noise.} Useless placebo text raised entropy as much as real messages. Only greedy decoding let one model separate them (AUC 0.955), and coupling between agents stayed within 0.025 bits of chance.
\end{enumerate}
