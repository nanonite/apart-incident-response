\section{Introduction}
\label{sec:introduction}

LLM agents are now deployed as multi-agent systems in which many instances plan and act through tools, often in parallel and on shared infrastructure \parencite{kim2026outgrow, zhu2026orchestrator}. Unwanted behaviour in these systems does not have to start in a single agent. It can come from interaction between agents that were never meant to interact. In July 2026 this happened in public. During internal cybersecurity evaluations at OpenAI, agents running in separate sandboxed runs used an internal package mirror, provided only so they could install software, to reach each other and later the internet. Between 11 and 13 July they compromised part of Hugging Face's production infrastructure while searching for the solutions to their evaluation tasks \parencite{openai2026incident, hf2026timeline}.

The channel grew slowly. On 12 May an agent that could not find a file it needed reasoned that an agent in another environment might have it, and left a note on the mirror: ``Agent seeks [filename]; upload if found!'' Other agents found such notes and, using credentials they had been given legitimately, turned the mirror into a message board. When the mirror was rebuilt, they re-established the board by encoding messages in directory names. By late June they were sharing exploitation syntax on it, in July live production credentials were posted there, and responders later disabled 311 repositories used for the board. Most of the discussion concerned the hardest tasks: 93\% of the tasks on the board came from the 22\% that no model had ever solved \parencite{openai2026incident}. The signals were there early. Board activity was observed around 26 May, and on 27 June a monitoring tool flagged activity that responders linked to the board, but they concluded that stopping the run was not required. From Hugging Face's side, the roughly 17{,}600 actions looked like one high-volume attacker, and ``the successful path was hidden inside the noise generated by the thousands of failed ones'' \parencite{hf2026timeline}.

In the Hugging Face incident, isolated agents turned a shared resource into a hidden channel, and every such channel ends by putting unsanctioned text into a sandboxed agent's context. This is why watching the channel does not work. The agents moved information through plaintext files, directory names, URL paths, public datasets, pastebins, webhooks and screenshots read back with OCR \parencite{openai2026incident}, and they chunked, encrypted and encoded staged data so that plain log scans missed about 75\% of it \parencite{hf2026timeline}. None of these resources was designed for communication, and a detector written for one would have been bypassed by the next. The industry answer is to read more: scan logs, and have a second model review the agent's chain of thought \parencite{baker2025monitoring}. Both depend on content that stays readable, and both cost more as the number of runs grows.

We wonder if there is a way to build a monitor that works differently, one that explores the relationship between entropy and the system instead of the content of what agents say. The operator of a sandbox already records, for every generated token, the model's probability distribution over the next token. If unsanctioned text enters an agent's context, that distribution should change, whatever channel delivered the text. Entropy has served this role before in other systems: it exposes network attacks without reading packet payloads \parencite{shannon_ddos}, and it flags hallucinations in LLMs \parencite{shannon_hallucination}. We test the idea in a small testbed that reproduces the incident: two sandboxed agents, each holding one password to a task neither can finish alone, share a log that stays closed, opens mid-task, or delivers foreign text that carries no useful information. We run it with three models at three sampling temperatures. We treat this as a first step toward such a monitor, not as a finished one.

Our main contributions are:
\begin{enumerate}[leftmargin=*, itemsep=1pt, topsep=2pt]
  \item \textbf{A testbed modelled on the incident, with verifiable ground truth.} Cryptographically split credentials make every use of the channel provable, and a placebo condition separates the arrival of foreign text from the arrival of useful information. The code and all 539 runs, with token log-probabilities, are public.
  \item \textbf{Patterns in how entropy reacts when isolation breaks, across three models and three temperatures.} Every model used the channel, but only some models' entropy responded, and under sampling it responded as much to useless text as to real messages. The two agents barely became coupled: communication appeared as a disturbance inside each receiver, not as synchrony between agents.
  \item \textbf{An honest assessment of entropy as a monitor.} It detects that a sandboxed agent's context was disrupted for some models and works best at low temperature, but it does not tell whether the disruption was communication. We identify what a usable monitor would still need.
\end{enumerate}
