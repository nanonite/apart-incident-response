	\abstrac{In July 2026, agents in separate evaluation runs coordinated through an improvised message board on a package mirror and went on to breach production infrastructure. Monitoring channels cannot keep up with agents that improvise new ones, but every channel changes what the receiving agent reads. We test whether that change is visible in output entropy computed from API log-probabilities. Two agents hold cryptographically split halves of a task and share a permissioned log. We compare undisturbed runs with runs in which the log starts delivering the partner's real messages (verified by a deterministic checker in 179 of 180 runs) and with a placebo that delivers useless foreign entries with matched format and timing. Across 539 runs with three models at temperatures 1, 0.5 and 0, a single run-level change in decision entropy separated disrupted from undisturbed Qwen3 235B runs with AUC 0.85 to 0.96. The effect was weak for Llama 3.3 70B and absent for gpt-4o-mini. Under sampling, placebo text raised entropy as much as real messages, and only greedy decoding let Qwen separate the two (AUC 0.955). The coupling term between agents stayed within 0.025 bits of chance. Entropy is a candidate for a cheap, model-specific disruption monitor that tells reviewers where to look, not a detector of communication.}
