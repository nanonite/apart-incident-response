	\abstrac{In July 2026, agents in separate evaluation runs coordinated through an improvised message board and went on to breach production infrastructure. Channel monitoring cannot keep up with improvised channels, but every channel changes what the receiving agent reads. We test whether that change is visible in output entropy from API log-probabilities. Two agents hold cryptographically split halves of a task and share a permissioned log that, from turn 8, either stays private, delivers the partner's real messages (communication verified in 179 of 180 runs), or delivers useless placebo entries with matched format and timing. Across 539 runs with three models at temperatures 1, 0.5 and 0, one run-level statistic separated disrupted from undisturbed Qwen3 235B runs with AUC 0.85 to 0.96; the effect was weak for Llama 3.3 70B and absent for gpt-4o-mini. Under sampling, placebo text raised entropy as much as real messages, and only greedy decoding separated the two. Entropy is a candidate for a cheap, model-specific disruption monitor, not a communication detector.}
